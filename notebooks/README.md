# Notebooks

Put the Colab notebook here, for example:

    Casey_FTC_Alliance_Forecaster_Consolidated.ipynb

Two ways to keep it in sync with GitHub:

1. In Colab: File > Save a copy in GitHub, choose this repository, and set the
   path to `notebooks/Casey_FTC_Alliance_Forecaster_Consolidated.ipynb`.
2. From a Colab cell using git, as described in the instructions document.

Before committing, run Cell > Run all so the saved outputs match the code.
